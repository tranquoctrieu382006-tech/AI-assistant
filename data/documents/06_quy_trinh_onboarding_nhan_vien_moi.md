---

## 1. Lộ trình tuần đầu tiên (First Week Milestone)

```
[Ngày 1: Nhận bàn giao & tài khoản]
       │
       ▼
[Ngày 2: Cài đặt môi trường & Clone repo]
       │
       ▼
[Ngày 3: Đọc tài liệu kiến trúc & Tìm hiểu nghiệp vụ]
       │
       ▼
[Ngày 4-5: Nhận task đầu tiên & Tạo PR đầu tay]
```

### Chi tiết các bước thực hiện:
- **Ngày 1 (Thủ tục & Thiết bị)**:
  - Nhận thẻ nhân viên, máy tính xách tay (hoặc máy trạm tại chỗ).
  - Kích hoạt email công ty (`@ioc.com.vn`), tài khoản Slack / Discord, tài khoản Jira.
  - Tham gia buổi giới thiệu văn hóa và nội quy công ty.
- **Ngày 2 (Thiết lập môi trường kỹ thuật)**:
  - Cài đặt Python 3.11+, Git, VS Code / Cursor / PyCharm.
  - Cài đặt Docker Desktop và Ollama để chạy mô hình AI nội bộ.
  - Cấu hình SSH Key trên GitLab công ty.
- **Ngày 3 (Tìm hiểu dự án)**:
  - Gặp gỡ Mentor phụ trách 1-1 để trao đổi về Kế hoạch thực tập / Mục tiêu thử việc.
  - Đọc tài liệu kiến trúc hệ thống (`docs/architecture.md`) và quy trình log work.
- **Ngày 4 – 5 (Thực hành)**:
  - Nhận ticket demo đầu tiên trên Jira.
  - Thực hành quy trình tạo nhánh, viết mã, chạy test và tạo Merge Request / Pull Request vào nhánh `develop`.
